# 谱行与小节切分实验

入口：选择 PDF →「分析谱行与小节」。无需 Audiveris，不运行自动修复。

每页分步分析，显示谱行数、小节数及原图框线。点击框内增加边界，点击已有内部边界删除；保存按钮导出 coordinates.json 和每页带框 PNG。原始 PDF 不变。

坐标单位为渲染图像像素，页码、行号、列号从 1 开始。各小节 box 与谱线位置保留，可用于后续音符识别和回查。当前只有坐标，不输出假音符或占位 MusicXML。

算法：灰度阈值、水平投影、五条近似等间距谱线匹配，长短谱表两级检测；纵向连续性寻找小节线，排除附带符头/连梁的符干。阈值尚为实验参数。

限制：目前单谱表分行，不合并钢琴或总谱系统；不处理严重旋转、弯曲谱线。相距三倍谱线间距以内的候选边界合并，极窄小节可能漏切。框的上下边距不是完整演奏记号裁切范围；后续识别需要更宽上下文。

样例 MERRY GO ROUND OF LIFE.pdf：6 页，第 6 页空白；音乐页谱行数 7、8、9、8、7，共 39 行。原谱每行 3 小节，总计 117 小节。此样例用于调参，不能代表未知谱面的准确率。

下一阶段：独立标注更多样例，建立切分边界评测；再读取谱号、调号、拍号，识别符头与时值并输出统一事件数据，最后转换 MusicXML。
